## Частина 1: Теоретичні відомості

### Впорядковані дерева (Rose Trees)

[cite\_start]**Впорядковане дерево** — це скінченна множина вузлів, в якій один вузол є **коренем**, а решта вузлів утворюють впорядкований список непересічних множин, кожна з яких, у свою чергу, є впорядкованим деревом[cite: 3]. [cite\_start]У Haskell такі дерева можна представити за допомогою типу `Rose a`[cite: 4]:

  * [cite\_start]Кожне дерево `Node v tx` містить значення в корені `v` та список піддерев `tx`[cite: 5].
  * [cite\_start]Список дерев називається лісом (`Forest a`)[cite: 7].

<!-- end list -->

```haskell
data Rose a = Node a (Forest a) deriving (Show, Eq)
type Forest a = [Rose a]
```

**Властивості:**

  * [cite\_start]Кожне дерево не є порожнім[cite: 9].
  * [cite\_start]Кожен вузол може мати будь-яку кількість нащадків (синів)[cite: 10].
  * [cite\_start]Усі нащадки одного вузла є впорядкованими (утворюють список)[cite: 11].

-----

### Двійкові дерева (Binary Trees)

[cite\_start]**Двійкове (бінарне) дерево** — це множина вершин, яка або є порожньою (`Tip`), або складається з кореня `v` та двох піддерев: лівого `tl` та правого `tr`[cite: 24].

```haskell
data Bin a = Tip | BNode a (Bin a) (Bin a) deriving (Show, Eq)
```

**Властивості:**

  * [cite\_start]Двійкове дерево може бути порожнім[cite: 27].
  * [cite\_start]Кожен вузол має 0, 1 або 2 нащадків[cite: 28].
  * [cite\_start]Розрізняють лівого та правого нащадка[cite: 29].

-----

### Відповідність між деревами

[cite\_start]Існує взаємно-однозначна відповідність між лісами впорядкованих дерев та двійковими деревами[cite: 36]. Перехід від лісу впорядкованих дерев до еквівалентного двійкового дерева можна описати так: у двійковому дереві **лівий нащадок** відповідає **першому сину** у впорядкованому дереві, а **правий нащадок** відповідає **наступному брату (сусіду)**.

[cite\_start]Наприклад, наступний ліс `otx` еквівалентний двійковому дереву `bt`[cite: 42]:

  * **Ліс `otx`:**

    ```haskell
    otx = [ Node 1 [Node 2 [], Node 3 [Node 10 []]],
            Node 4 [Node 5 [Node 8 []], Node 6 [Node 9 []], Node 7 []] ]
    ```

  * **Двійкове дерево `bt`:**

    ```haskell
    bt = BNode 1 (BNode 2 Tip (BNode 3 (BNode 10 Tip Tip) Tip))
                 (BNode 4 (BNode 5 (BNode 8 Tip Tip) (BNode 6 (BNode 9 Tip Tip) (BNode 7 Tip Tip))) Tip)
    ```

### Двійкові дерева пошуку (Binary Search Trees)

[cite\_start]**Двійкове дерево пошуку** — це двійкове дерево, в якому для будь-якого вузла `v` всі значення в його лівому піддереві є меншими або рівними `v` ($$u \le v$$), а всі значення в правому піддереві — більшими за `v` ($$u > v$$)[cite: 70].

[cite\_start]Основна властивість: **центрований обхід** (in-order traversal) двійкового дерева пошуку повертає відсортований список елементів у неспадаючому порядку[cite: 73]. [cite\_start]Ця властивість використовується для сортування списків[cite: 74].

## Частина 2: Практичне завдання

### Функції для реалізації

1.  **`dfsForest`**

      * [cite\_start]**Опис:** Формує список елементів лісу впорядкованих дерев, отриманий при обході в глибину[cite: 79].
      * [cite\_start]**Тип:** `Forest a -> [a]` [cite: 106]
      * [cite\_start]**Приклад:** `dfsForest otx` повинно повернути `[1,2,3,10,4,5,8,6,9,7]`[cite: 81].

2.  **`bfsForest`**

      * [cite\_start]**Опис:** Формує список елементів лісу впорядкованих дерев, отриманий при обході в ширину[cite: 82].
      * [cite\_start]**Тип:** `Forest a -> [a]` [cite: 107]
      * [cite\_start]**Приклад:** `bfsForest otx` повинно повернути `[1,4,2,3,5,6,7,10,8,9]`[cite: 84].

3.  **`toBin`**

      * [cite\_start]**Опис:** За списком впорядкованих дерев будує відповідне двійкове дерево[cite: 85].
      * [cite\_start]**Тип:** `Forest a -> Bin a` [cite: 108]
      * [cite\_start]**Приклад:** `toBin otx` повинно повернути `bt`[cite: 86].

4.  **`fromBin`**

      * [cite\_start]**Опис:** За двійковим деревом будує відповідний список впорядкованих дерев[cite: 87].
      * [cite\_start]**Тип:** `Bin a -> Forest a` [cite: 109]
      * [cite\_start]**Приклад:** `fromBin bt` повинно повернути `otx`[cite: 88].

5.  **`isSearch`**

      * [cite\_start]**Опис:** Перевіряє, чи є двійкове дерево двійковим деревом пошуку[cite: 89].
      * [cite\_start]**Тип:** `(Ord a) => Bin a -> Bool` [cite: 110]
      * [cite\_start]**Приклади:** `isSearch bin1` -\> `True` [cite: 90][cite\_start], `isSearch bin2` -\> `False`[cite: 91].

6.  **`elemSearch`**

      * [cite\_start]**Опис:** Перевіряє, чи містить двійкове дерево пошуку вузол із заданим значенням `v`[cite: 92].
      * [cite\_start]**Тип:** `(Ord a) => Bin a -> a -> Bool` [cite: 111]
      * [cite\_start]**Приклади:** `elemSearch bin1 3` -\> `True` [cite: 94][cite\_start], `elemSearch bin1 10` -\> `False`[cite: 95].

7.  **`insSearch`**

      * [cite\_start]**Опис:** Вставляє в двійкове дерево пошуку новий вузол зі значенням `v`[cite: 96].
      * [cite\_start]**Тип:** `(Ord a) => Bin a -> a -> Bin a` [cite: 112]
      * [cite\_start]**Приклад:** `insSearch bin1 5` повинно повернути `bin3`[cite: 98].

8.  **`delSearch`**

      * [cite\_start]**Опис:** Вилучає з двійкового дерева пошуку один вузол зі значенням `v`[cite: 99]. [cite\_start]Якщо такого вузла немає, дерево не змінюється[cite: 100].
      * [cite\_start]**Тип:** `(Ord a) => Bin a -> a -> Bin a` [cite: 113]
      * [cite\_start]**Приклади:** `delSearch bin3 5` -\> `bin1` [cite: 101][cite\_start], `delSearch bin1 5` -\> `bin1`[cite: 102].

9.  **`sortList`**

      * [cite\_start]**Опис:** Сортує список, використовуючи двійкове дерево пошуку[cite: 103].
      * [cite\_start]**Тип:** `(Ord a) => [a] -> [a]` [cite: 114]
      * [cite\_start]**Приклади:** `sortList [30,6,23,9]` -\> `[6,9,23,30]` [cite: 104][cite\_start], `sortList "LearnHaskell"` -\> `"HLaaeekllnrs"`[cite: 105].
